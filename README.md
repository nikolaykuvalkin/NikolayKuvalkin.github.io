# 💻 Компьютерный мастер — GitHub версия

Этот проект подготовлен для публикации на **GitHub Pages**.

## 📂 Содержимое
- index.html  
- style.css  
- script.js  
- README.md

## 🚀 Публикация

1. Создай репозиторий на GitHub  
2. Загрузите эти файлы в корень (`/`)  
3. Открой Settings → Pages  
4. Branch: `main`, Folder: `/root`  
5. Нажми **Save**

Сайт появится по адресу:  
`https://<your_name>.github.io/<repo_name>/`
